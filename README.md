# AutoIncome AI — CreatorKit

Responsive, free creator tools that run entirely in the browser.

## Features
- ROI and profit calculator
- YouTube title ideas (template-based, not generative AI)
- Seven-day content planner

## Run
Open `index.html` in a browser. No dependencies or API keys are required.

## Publish
Connect this repository's `main` branch to Cloudflare Pages using static HTML deployment. No build command is necessary; publish the repository root.

## Revenue roadmap
1. Publish original, useful English content and improve SEO.
2. Measure traffic and validate demand.
3. Add compliant affiliate links or advertising after approval, with appropriate disclosures.
4. Add premium digital products if users show demand.

**No passive income is guaranteed.** This release has no ads, payment integration, affiliate links, backend AI, or automated content publication. Browser inputs are processed locally. Add a privacy policy and legal notices before integrating third-party analytics or advertising.
